# Session transcript: Cash App install attempt (2026-09-29)

Reproduction recipe and error transcript from the original Cash App download/install task. For diagnosing future Termux APK tasks.

## Environment (this device)
- Host: Android 16, aarch64, kernel 6.1.145-android14
- Shell user: `u0_a288` (Termux sandbox)
- Package managers present: `apt`, `pkg`, `dpkg`, `pm`, `am`
- `su` present but reports "No su program found on this device" — no root escalation.
- Internet works (Cash App homepage returned HTTP 200).
